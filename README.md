## Struktur Fungsi

1. salam() menampilkan salam berdasarkan nama dan kelas.
2. luas_persegi_panjang() menghitung luas persegi panjang.
3. jumlah_n() menghitung jumlah bilangan dari 1 sampai n.
4. statistik() menghasilkan nilai minimum, maksimum, dan rata-rata.
5. demo() menunjukkan penggunaan parameter dan scope variabel.
6. luas_segitiga() menghitung luas segitiga.
7. faktorial() menghitung faktorial bilangan.
8. tampilkan_menu() menampilkan pilihan operasi.
9. main() mengatur jalannya program utama.

Fungsi perhitungan menggunakan return agar hasilnya bisa digunakan
kembali oleh bagian program lainnya.

## Hasil Pengujian

- Luas persegi panjang dengan panjang 8 dan lebar 5 menghasilkan 40.
- Luas segitiga dengan alas 10 dan tinggi 6 menghasilkan 30.0.
- Jumlah bilangan dari 1 sampai 10 menghasilkan 55.
- Faktorial 5 menghasilkan 120.
- Faktorial 0 menghasilkan 1.

## Refleksi

Penggunaan fungsi membuat program lebih terstruktur karena setiap
fungsi mempunyai tugas masing-masing. Parameter digunakan untuk
menerima data, sedangkan return digunakan untuk mengembalikan hasil
perhitungan. Dengan demikian, rumus dapat digunakan kembali tanpa
harus menuliskan ulang seluruh proses perhitungan.
